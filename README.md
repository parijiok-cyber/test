# 맞춤법 돋보기 — Google Sheets + Apps Script 웹앱

6모둠(넷이서 간다!) 기획서를 기반으로 제작한 실행 코드입니다. 학생 손글씨 사진을 업로드하면
Upstage AI가 글자를 읽고(Document Digitization OCR), Solar 챗 모델이 맞춤법·띄어쓰기 오류를
찾아 설명해주고, 오류가 없으면 학년 맞춤 추천 단어를 보여줍니다. 학생들이 자주 틀리는 표현은
스프레드시트에 자동으로 누적되고, 그 데이터로 반 전체가 함께하는 OX퀴즈·골든벨 퀴즈를
즉석에서 만들어줍니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `Code.gs` | 서버 로직 — Upstage OCR·Chat API 호출, 시트 저장, 퀴즈 생성 |
| `Index.html` | 메인 화면 — 손글씨 사진 업로드 & 결과 |
| `QuizPage.html` | 반 전체 퀴즈 화면 — OX퀴즈 / 골든벨 |
| `CSS.html` | 공통 스타일 |
| `IndexJS.html` | 메인 화면 클라이언트 스크립트 |
| `QuizJS.html` | 퀴즈 화면 클라이언트 스크립트 |

## 설치 방법 (10분이면 충분해요)

### 1. 스프레드시트 만들기
1. 새 Google 스프레드시트를 하나 만듭니다. (이름 예: `맞춤법 돋보기 데이터`)
2. 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 클릭합니다. 이렇게 하면 이 스크립트가
   해당 스프레드시트에 "바인딩"되어, 별도 설정 없이 같은 시트에 데이터를 저장합니다.

### 2. 코드 붙여넣기
1. Apps Script 편집기에서 기본 `Code.gs` 내용을 지우고, 이 프로젝트의 `Code.gs` 내용을 그대로 붙여넣습니다.
2. 왼쪽 **파일 추가(+) → HTML** 을 눌러 아래 5개 파일을 각각 만들고, 같은 이름의 `.html` 내용을 그대로 붙여넣습니다.
   - `Index` (Index.html 내용)
   - `QuizPage` (QuizPage.html 내용)
   - `CSS` (CSS.html 내용)
   - `IndexJS` (IndexJS.html 내용)
   - `QuizJS` (QuizJS.html 내용)
   - ⚠️ Apps Script에서 파일 이름은 확장자 없이 만드셔야 합니다 (예: `Index`, `CSS`).

### 3. Upstage API 키 설정
1. [console.upstage.ai](https://console.upstage.ai/api-keys) 에서 API 키를 발급받습니다. (`up_...` 형태의 키)
2. Apps Script 편집기 왼쪽 톱니바퀴(**프로젝트 설정**) → **스크립트 속성** → **속성 추가**
   - 속성: `UPSTAGE_API_KEY`
   - 값: 발급받은 키 (`up_...`로 시작)
3. (선택) 맞춤법 교정에 쓰는 Solar 모델을 바꾸고 싶다면 `UPSTAGE_CHAT_MODEL` 속성을 추가해 모델 ID를
   지정하세요. 비워두면 `Code.gs`의 `UPSTAGE_CHAT_MODEL_DEFAULT`(`solar-pro2`) 값을 사용합니다.
   최신 모델 목록은 [Upstage 콘솔](https://console.upstage.ai/)에서 확인할 수 있습니다.
4. (스프레드시트에 바인딩하지 않고 독립 스크립트로 쓰는 경우에만) `SPREADSHEET_ID` 속성도 추가하세요.

### 4. 웹앱으로 배포
1. 우측 상단 **배포 → 새 배포**
2. 유형: **웹 앱**
3. 실행 계정: **나(교사 본인)**
4. 액세스 권한: 학교 상황에 맞게 선택
   - 학생들이 개인 기기로 접속 → "Google 계정이 있는 모든 사용자" 또는 "학교 조직 내 전체"
   - 교실 공용 화면(대시보드/퀴즈)만 필요 → "링크가 있는 모든 사용자"도 가능
5. **배포**를 누르면 웹앱 URL이 생성됩니다. 이 URL을 학생들에게 공유하세요.

### 5. 확인
- 기본 URL(`.../exec`)로 들어가면 **글씨 검사하기** 화면이 뜹니다.
- `.../exec?page=quiz` 로 들어가면(또는 화면 위 "반 전체 퀴즈" 탭) 누적된 오류로 만든
  OX퀴즈·골든벨 화면이 뜹니다. 이 화면을 교실 TV/전자칠판에 띄우고 다 같이 풀면 좋아요.

## 동작 흐름 (기획서 8번과 대응)

1. **입력**: 학생이 손글씨 사진을 업로드하고, (선택) 학년·익명 코드를 입력합니다.
2. **처리**: Upstage OCR(Document Digitization)이 사진 속 글씨를 텍스트로 읽고, Solar 챗 모델이
   그 텍스트에서 맞춤법·띄어쓰기 오류를 찾아 이유를 생성합니다. 오류가 없으면 학년 수준의
   추천 단어를 대신 제시합니다. 오류가 있으면 `오류기록` 시트에 한 줄씩 자동 저장됩니다.
3. **결과**: 원문 · 오류 비교(원본→교정) · 이유 · 칭찬 메시지가 화면에 나타납니다.
   누적된 오류는 **반 전체 퀴즈** 탭에서 OX퀴즈·골든벨로 재활용됩니다.

## 개인정보 보호 (기획서 5번 반영)

- 학생 이름은 실명 대신 번호/코드로 입력하도록 화면에 안내되어 있습니다.
- 업로드된 사진 자체는 저장하지 않고, 분석에만 사용한 뒤 버립니다. 시트에는 텍스트(오류 표현·이유)만 저장됩니다.

## 알아두면 좋은 점 / 향후 개선 아이디어 (멘토 질문 9번 관련)

- 사진 한 장을 검사할 때마다 Upstage API가 두 번(OCR 1회 + Solar 챗 1회) 호출됩니다.
  사용량만큼 과금되니 학급 인원이 많다면 예상 호출 횟수 기준으로 비용을 미리 가늠해보세요.
  (`Code.gs`의 `fetchWithRetry_` 가 일시적 오류(429, 5xx)는 자동 재시도하고, API 키 오류 등은
  즉시 실패로 알려줍니다.)
- 손글씨 인식 정확도는 사진 밝기·기울기에 영향을 받습니다. 학생들에게 "글씨가 화면에
  꽉 차게, 그림자 없이" 촬영하도록 안내하면 인식률이 올라갑니다.
- OCR과 맞춤법 판단이 두 단계로 분리되어 있어서, OCR이 글자를 잘못 읽으면(예: "ㅁ"을 "ロ"로
  인식) 그 오류까지 맞춤법 오류로 잘못 지적될 수 있습니다. `correctText_` 함수의 프롬프트에서
  OCR 인식 오류는 무시하도록 안내하고 있지만, 실제 사용해보며 프롬프트를 다듬어보세요.
- 지금은 오류 유형을 `맞춤법/띄어쓰기/표준어` 중 AI가 자유롭게 분류합니다. 학교 자체
  기준으로 유형을 더 세분화하고 싶다면 `Code.gs`의 `correctText_` 함수 프롬프트를 수정하세요.
